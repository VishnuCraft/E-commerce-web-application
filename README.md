# E-commerce-web-application

This is a full-fledged E-commerce Web Application built with an Admin Panel and a Frontend for the customers. It uses MySQL for the database management and is designed to help businesses set up their online store efficiently.

**Admin Panel:**

Manage Products (Add, Edit, Delete)

Manage Users and Orders

View Reports

Inventory Management

**Frontend:**

User Authentication (Signup/Login)

Product Catalog and Search

Add to Cart and Checkout

Order Management

Payment Gateway Integration (if implemented)

Tech Stack

**Frontend:** HTML, CSS, JavaScript (can also include frameworks like React, Vue, or Angular if used)

**Backend:** PHP, or any backend technology used

**Database:** MySQL
